# HealthCare+ Figma Mockups

This folder contains static HTML + Tailwind pages for the HealthCare+ UI mockup—a complete, premium SaaS design system ready for Figma recreation or frontend implementation.

## What to open
- **`index.html`** — interactive page gallery with navigation to all screens

## Main App Pages
- `login.html` — authentication page
- `register.html` — account creation page
- `dashboard.html` — main operational overview
- `patients.html` — patients list with summary
- `doctors.html` — doctors directory
- `appointments.html` — appointment scheduling
- `records.html` — medical records
- `prescriptions.html` — medication management
- `analytics.html` — performance insights
- `settings.html` — user preferences
- `about.html` — brand page

## Form Pages (Create & Edit)
- `add-patient.html` — create new patient form
- `edit-patient.html` — update patient form with delete option
- `add-doctor.html` — register new doctor form
- `edit-doctor.html` — update doctor form with deactivate option
- `add-appointment.html` — schedule new appointment form
- `edit-appointment.html` — reschedule appointment form with cancel option

## How to use
1. Open `index.html` in browser
2. Click any page card to view
3. Copy sections for Figma mockups
4. Use as frontend implementation reference

## Design System
- **Primary color:** `#2563EB` (brand-600)
- **Secondary color:** `#06B6D4` (cyan-500)
- **Background:** `#F8FAFC` (slatebg)
- **Cards:** white with soft shadows
- **Typography:** clean, modern, accessible
- **Spacing:** 8px grid system
- **Radius:** large, rounded-2xl / rounded-3xl

## Features
- Responsive design (mobile, tablet, desktop)
- Sidebar + topbar + content layout
- Premium form validation UI
- Status badges and chips
- Tables and lists with hover states
- Activity feeds and quick actions
- Profile and settings components
- Empty states and skeleton loaders (placeholders)
